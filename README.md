# AMOUR

AMOUR is an anonymous love-chronicles archive built with React Router, React, TypeScript, and Tailwind CSS. The app lets visitors browse fictional missed connections, spin through letters by mood, save favorites to a sanctuary drawer, add comments, and submit a new anonymous letter into the local session archive.

## Tech Stack

- React Router 7
- React 19 with TSX components
- TypeScript
- Tailwind CSS 4
- shadcn-style Radix UI primitives
- Framer Motion and Howler for interaction and soundscape details

## Project Structure

```text

|-- components/

|-- lib/                # Shared utilities
|-- routes/             # Route entry files

```

## Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The app is available at `http://localhost:5173`.

## Verification

Run TypeScript checks:

```bash
npm run typecheck
```

Create a production build:

```bash
npm run build
```

## Deployment

Build and run the container:

```bash
docker build -t amour .
docker run -p 3000:3000 amour
```

For Node hosting, deploy the output generated by `npm run build`.
